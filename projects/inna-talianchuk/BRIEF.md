## 5. Концепция 3D-героя главной страницы ("Хаос → Ясность")

Это центральный визуальный аттракцион сайта — сцена, которая **буквально исполняет обещание бренда**.

### Идея
При заходе на сайт открывается длинная (⁓520vh) закреплённая (pinned) секция. Пока пользователь скроллит:
1. Экран показывает сцену с **рассеянными частицами/обломками** (графит + оливковый), дрейфующими в беспорядке в левой части кадра
2. Справа — **упорядоченная 3D-решётка** (архитектурная сетка линий с узлами тёплого золотого/шампань цвета), изначально построенная примерно на треть
3. По мере скролла: решётка достраивается линия за линией (волной по сетке), а каждая частица слева **стягивается в свой узел решётки**, на лету перекрашиваясь в цвет шампань — хаос буквально поглощается структурой
4. Камера медленно и плавно поднимается вверх на протяжении всего скролла
5. Поверх сцены — крупный центральный serif-заголовок и 5 последовательных «глав» повествования, сменяющих друг друга по мере скролла:

| № | Глава | Текст |
|---|---|---|
| 01 | **Complexity / Сложность** | «Modern business grows more complex every day. AI, automation, dozens of services, data. They create opportunities — but on their own they make business more complex, not more efficient.» |
| 02 | **Clarity / Ясность** | «My work is not to add new tools. My work is to create a system where everything works together.» |
| 03 | **Systems / Системы** | «Strategy, marketing, AI, operations. Connected into one workflow. Each part reinforcing the others.» |
| 04 | **Growth / Рост** | «When the system works, the business grows. Predictably. Sustainably. Without constant firefighting.» |
| 05 | **Freedom / Свобода** | «And you get the one thing that matters most: freedom to focus on what you do best.» |

Тег-лайн над заголовком: **«Complexity is inevitable. Chaos is optional.»**

### Технические детали реализации (референс для реализации на любом стеке)
- Технология: React Three Fiber (Three.js) внутри React/Next.js, привязка прогресса сцены к прогрессу скролла страницы (`scrollYProgress` от 0 до 1)
- Палитра сцены: графит `#2A302C` и оливка `#6F7A5A` (частицы), тёплое золото `#A8823F`/`#C2A15F` (узлы решётки), линии `#565F50`
- Свечение имитируется тёплыми оттенками и туманом (`THREE.Fog`), **не** через additive blending (иначе на светлом фоне будет вымывать цвет)
- Решётка: 3D-сетка (6×5×3 узлов), каждый сегмент линии строится из своего центра наружу, с шаговой задержкой (stagger) по позиции в сетке
- Частицы: у каждой — случайная стартовая позиция (хаос) и целевой узел решётки (порядок), интерполяция по сглаженной кривой (smoothstep) от прогресса скролла
- Обязательные fallback-и:
  - **`prefers-reduced-motion: reduce`** → вся хореография отключается, показывается статичный герой + список из 5 глав друг под другом без анимации
  - **Мобильные устройства** (< 768px) → вместо WebGL-сцены — лёгкий CSS-фон, имитирующий решётку (`repeating-linear-gradient`), без Three.js
  - 3D-сцена подключается динамически (`dynamic import`, `ssr:false`), чтобы не блокировать первую загрузку страницы

### История эволюции этой концепции (для контекста)
1. Первая версия была реализована в **тёмной** палитре (чернильный фон `#0F1311`, нити/threads вместо частиц) — по референсу видео с Higgsfield (`complexity-to-clarity.higgsfield.app`), но с заменой их кислотно-зелёной палитры и цветовых "россыпей точек" на фирменный тёплый графит/шампань.
2. По финальному пожеланию — версия была **перекомпонована в светлую премиальную палитру**, сохранив композицию видео-референса (хаос слева / решётка справа / доминирующая типографика по центру), но полностью заменив тёмный фон на светлый (порцелан/слоновая кость), без стороннего брендинга.
3. Финальная версия — именно светлая, это последнее согласованное решение.

**Если у выбранного сервиса нет возможности собрать полноценную 3D WebGL-сцену** — приемлемая деградация: тот же нарратив (5 глав, та же цветовая динамика) реализовать через 2D SVG/CSS-анимацию с той же логикой "частицы → узлы решётки", сохранив кинематографичность и pinned-scroll поведение.

### 7.3 Approach / Подход (`/approach`)

Hero: **«Clarity before tools.»** / «Ясность прежде инструментов.» — работа начинается с бизнес-цели и текущего процесса, а не с выбора софта.

**5-шаговый процесс** (Understand → Analyze → Design → Implement → Optimize), для каждого шага:
- Что в фокусе (конкретные подтемы)
- Какие вопросы решаются
- Какая работа выполняется
- Какой результат поставляется
- Какое участие требуется от клиента

Визуально — те же шаги представлены как непрерывная линия/путь, "активирующаяся" по мере скролла (каждый шаг подсвечивается индикатором при входе в зону видимости), с полностью читаемым текстом без анимации и статичной вертикальной версией при `prefers-reduced-motion`.

**6 принципов работы:**
1. Systems before tools — сначала структура, потом софт
2. Technology serves people — инструменты облегчают работу, а не наоборот
3. Clear responsibility — за каждым шагом закреплён один ответственный
4. Measurable decisions — решения на основе данных, а не предположений
5. Sustainable implementation — решения, которые продолжают работать после завершения проекта
6. Documentation is part of delivery — без документации внедрение не считается завершённым

Плюс: объяснение форматов проектов, ожидания по коммуникации, FAQ, CTA.

## 8. SEO / GEO и техническая база

- `generateMetadata` на каждой странице × локали: уникальные title/description, OG/Twitter-теги
- hreflang + self-referencing canonical на каждую локаль + `x-default` → немецкая версия
- JSON-LD структурированные данные:
  - **Person** — имя, должность, изображение (портрет), `knowsAbout` (области экспертизы)
  - **ProfessionalService** — с перечнем 5 услуг, `availableLanguage`
  - **WebSite**
  - **BreadcrumbList** — на всех внутренних страницах
  - **FAQPage** — **только** там, где FAQ реально видим на странице (не эмитируется "про запас")
  - **ItemList** — для списка услуг
  - **Service** — на каждой странице отдельной услуги
- **GEO (AI-answer-engine readiness):** каждое описание услуги/кейса начинается с самодостаточного декларативного предложения + отдельная строка «Result:», чтобы LLM-краулер мог извлечь «что делает» / «какой результат» без окружающего контекста
- Семантический HTML: один `<h1>` на страницу, строгий порядок заголовков, реальные landmarks

## 9. Доступность (WCAG 2.2 AA) — обязательные требования

- Skip-to-content ссылка
- Полная клавиатурная доступность, видимый focus-ring (замена, если `outline` убран)
- **Контраст**: минимум 4.5:1 для обычного текста, 3:1 для крупного — **проверено программно** (при аудите найдена и исправлена ошибка: изначальный оттенок шампань `#8A6F3C` для мелких надписей давал только 4.32:1 — заменён на `#7C6436`, ~5:1)
- `prefers-reduced-motion` — учитывается и глобальным CSS-переключателем, и в самой логике 3D-сцены (не полагаться только на один механизм)
- Все интерактивные элементы ≥44×44px, зазор между ними ≥8px
- Все icon-only кнопки — с `aria-label`
- Alt-текст у портретов — описательный (имя + должность), декоративные элементы — `alt=""` / `aria-hidden`
- z-index — по заданной шкале (10/20/40/50), никаких произвольных `z-[9999]`
- Изображения — ленивая загрузка по умолчанию, самостоятельный хостинг шрифтов без layout shift

## 10. Анимация — общие правила

- Один согласованный набор motion-примитивов: fade+lift (`revealUp`), появление слева (`revealLeftToRight`), лёгкая дуга вверх, scale 0.97→1, стаггер групп ≤0.06–0.07с между элементами
- Тайминг: вход 0.45–0.75с, hover 0.18–0.28с, calm easing (`cubic-bezier(0.16, 1, 0.3, 1)` на вход)
- Никаких анимаций дольше 500мс для UI-переходов
- Единственная бесконечная (`repeat: Infinity`) анимация на сайте — стрелка-подсказка «скроллите вниз» в hero, и та гаснет, как только пользователь начинает скроллить (не чисто декоративная — навигационная подсказка)
- Все скролл-триггерные анимации — building block: «once: true» (не повторяются при обратном скролле)

## 11. Явные ограничения контента (важно!)

- **Не придумывать**: бизнес-показатели, клиентские кейсы, статистику, отзывы, сертификаты, гарантии
- **Не изобретать** интеграции с ПО, которое реально не используется
- **Не переименовывать** реальные сертификаты/квалификации — только точные названия
- **Не раскрывать** конфиденциальную информацию о работодателях
- **Не выдавать** внутреннюю работу за коммерческий клиентский кейс без разрешения
- Избегать размытых маркетинговых фраз («unlock your potential» и подобных)
- Каждое обещание услуги — уравновешено честным «what this does NOT promise»
- ИИ — всегда инструмент в процессе, не подрядчик/исполнитель услуги

## 12. Референсы (для настроения, не для копирования один в один)

- Видео-концепт с higgsfield.ai (`complexity-to-clarity.higgsfield.app`) — источник композиции 3D-сцены (хаос слева / решётка справа / крупная типографика по центру / трансформация по скроллу). **Цветовая палитра и эффект "рассыпанных точек" из этого референса НЕ используются** — только структура и динамика переосмыслены в фирменной светлой палитре.
